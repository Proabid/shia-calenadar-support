# Shia Calenadar support

Public support and privacy pages for the free Shia Calenadar app.

Developer: Abdulbari abdlbari. Support: ettavett@gmail.com.

Files are static HTML/CSS with no analytics or tracking scripts. GitHub Pages publishes the main branch root. `.nojekyll` disables Jekyll processing.

The app covers only the verified Sistani timetable for 1448 AH (17 June 2026–5 June 2027). This is an independent app, not an official app of Sistani’s office.
